# Galeon AeroMeter 使用说明书 V1

**适用固件：1.2.1 开发候选版（尚待实机验收）**
**配套桌面程序：Windows 1.2.1 正式版（build 11）**
**最后更新：2026-10-03**

> 本说明书对应仅恢复气压开机归零、气流不归零的候选固件，主界面共6页。

本文供最终用户使用，也提供第三方软件开发的公开接口入口。桌面程序版本与设备固件版本分别管理；将桌面程序更新为正式版不会自动更新设备固件。发货前应由供应方完成对应硬件的启动、测量、USB/BLE 与升级验收；上述固件候选状态不代表已通过实机验收。

首次使用：保持气路干燥、气压口与大气相通 → 无吹气开机 → 确认无红色错误 → 按进/出气标记接好被测气路 → 缓慢增加气流，看到 `OVER` 立即减小输入。使用电脑前也须完成这些检查。

## 1. 产品用途

AeroMeter 是一台便携式气压与气体流量测量仪，当前主要用于管乐器、簧片、气囊及相关气路的吹奏压力和耗气量测试。

主要测量规格：

| 测量项目 | 量程 | 传感器精度 |
|---|---:|---:|
| 气压 | 0–10 kPa | ±0.25% FS（满量程），对应约 ±0.025 kPa，即 ±25 Pa |
| 气流 | 0–50 L/min | ±1.5% |

设备采用触摸屏操作，气流通道内部已经安装约10 cm直管，无需用户另外加装直管。

表中精度是两个传感器的厂家标称指标，不是整机校准证书，也不意味着所有温湿度、气路和气体条件下都达到该精度。气流 ±1.5% 的具体定义及适用条件以随设备提供的厂家资料/报告为准，不应自行理解为满量程误差或读数百分比。两位小数方便观察变化，不代表最后一位具有同等准确度。累计气量、P/Q 和 Power 是计算值，没有单独承诺的整机精度。

本设备面向乐器和一般气路观察，不用于医疗诊断、呼吸机控制、生命支持、压力安全保护或贸易结算。未明确验证的气体、腐蚀性/可燃气体不得接入。

显示单位为 L/min；厂家校准气体、标准/参考温压条件及流量定义以交付资料为准。软件不自动补偿任意气体成分或环境温压，不将累计结果直接视为任意条件下的实际体积。

## 2. 开机与环境检查

### 2.1 开机条件

开机检查两个传感器的连接和数据读取，并仅对气压进行零点偏移补偿：连续读取32次气压，取平均值作为本次开机的零点，后续气压读数减去该偏移。例如开机零点为0.03 kPa，后续读数会扣除0.03 kPa。气流仍不归零、不扣除开机气流偏移，只作气流提醒。

两个传感器的厂家换算保持不变。气压零点只在本次开机期间有效，重新开机会重新测定，不改写传感器或校准报告，也不提升标称精度。

- 气压口必须无外加压力、与大气相通；不要带压启动；
- 建议将设备放稳，避开风扇、空调出风口等直接气流；
- 检查和气压归零期间不要吹气或挤压软管，否则可能错误扣除实际压力，或触发归零错误/气流提醒；
- 不需要为气流堵住进风口或出风口，不要密封气路造成残压；
- 保持接口及内置气路干燥、无异物。

### 2.2 启动进度画面

开机显示 Galeon AeroMeter、固件版本和检查进度，顶部提示 `PRESSURE ZERO / FLOW ZERO OFF`（气压归零／气流不归零）。

| 显示 | 含义 |
|---|---|
| `CHECKING SENSORS` | 检查两个传感器是否连接并正常响应 |
| `PRESSURE ZERO` | 采样并进行气压零点补偿，同时检查气流幅值 |
| `READY` / 100% | 检查完成，进入第一页 |

气压归零和气流检查共用32次短时采样，采样间隔合计约0.32秒，另有通信、屏幕更新及其他开机耗时，不另增加一段气流校准。

### 2.3 气流提醒与传感器错误

气压归零成功后，再按以下方式处理气流提醒：

- 短时平均气流幅值低于 `0.50 L/min`：自动进入主界面。
- 达到或超过 `0.50 L/min`：显示 `POSSIBLE AIRFLOW`（可能有气流）、`AVG |FLOW|`（本次检查的平均气流幅值，L/min）和 `TAP TO CONTINUE`。留意环境及气路后，单击屏幕即可继续；不要求重新测试通过。
- 这是提示，不是校准失败，也不能仅凭此判断有风或传感器损坏；实际气流、零点偏差等都可能触发提示。
- 传感器缺失、读取失败或气流数据校验失败：显示红色 `SENSOR WARNING` 及具体原因。正常测量应检查供电和连接并重新启动；如仅需进入设备信息页进行序列号登记或维护，可持续按住屏幕 3 秒跳过。
- 跳过后仍可切换全部六页；压力页或流量页会以红色文字提示对应传感器不可用。若气压传感器已连接，但启动检查因另一传感器失败而在气压归零前中断，压力页显示 `PRESSURE ZERO NOT APPLIED`。这种状态只用于维护，不能作为有效测量或整机启动通过。装好传感器后必须重新启动，完成正常检查和气压归零再测量。

气压零点平均值须在 ±0.25 kPa 内，且采样期间不能出现压力正向超量程；不满足时显示 `PRESSURE ZERO FAILED`、本次平均值和限值，不能跳过。请解除外加压力、让气路与大气相通后重新启动。±0.25 kPa 是防止错误归零的保护门限，不是传感器精度。

自动检查及气压归零期间暂停普通触摸；出现气流提醒时允许单击确认，出现传感器警告时可持续按住 3 秒进入维护界面；进入主界面后恢复正常触摸。`PRESSURE ZERO FAILED` 仍不能跳过。

气流未归零，静止时仍可能有小幅正读数；气压在补偿后也可能存在少量噪声或漂移。补偿后的负气压、负气流均按 `0.00` 显示；截零处理本身不提高传感器精度。

## 3. 基本操作

- 在屏幕上向上或向下滑动切换页面；
- 右侧圆点表示当前所在页面；
- 页面圆点在操作后显示，约3秒无操作会自动隐藏；
- 第4页 `STATISTICS` 支持双击打开数据清除确认框；
- 触摸屏时背光恢复正常亮度；
- 在前3页处于 `IDLE` 状态约5秒后，背光降低到约10%；
- 第4、5、6页保持正常亮度。

当前页面顺序：

1. 综合测量页；
2. 气压曲线页；
3. 气流曲线页；
4. 统计页；
5. 蓝牙页；
6. 设备信息页。

## 4. 第一页：综合测量

第一页同时显示实时气压、实时气流、短期波动、稳定状态和气动派生参数。

### 4.1 PRESSURE

经过本次开机零点补偿及滤波的气压，单位为 `kPa`。

- 主界面显示两位小数，例如 `1.82 kPa`；
- 气压传感器量程为 0–10 kPa；
- 气压传感器精度为 ±0.25% FS，10 kPa满量程对应约 ±25 Pa，即 ±0.025 kPa；
- 负读数统一显示为 `0.00 kPa`；
- 达到正向满量程时显示红色 `OVER`；负读数按0处理，不显示 `OVER`。

### 4.2 FLOW

实时滤波气流，单位为 `L/min`。

- 主界面保留两位小数；
- 小于 `0.10 L/min` 的零点残差显示为零；
- 流量传感器精度为 ±1.5%，量程为 0–50 L/min；达到上限时显示红色 `OVER`。

### 4.3 Σ

`Σ` 表示最近1秒数据的标准差，用于观察气压或气流的短期波动程度。

- 数值越小，输出越平稳；
- 压力 Σ 的单位为 kPa；
- 流量 Σ 的单位为 L/min。

### 4.4 P-P

`P-P` 表示最近1秒内的峰峰值：

`P-P = 最大值 - 最小值`

它反映最近1秒内的总波动范围。P-P 越小，测量越稳定。

### 4.5 状态指示

| 状态 | 颜色 | 含义 |
|---|---|---|
| `IDLE` | 灰色 | 当前压力小于0.30 kPa且流量小于1.0 L/min |
| `ACTIVE` | 橙色 | 已有明显压力或气流，但尚未满足稳定条件 |
| `STABLE` | 绿色 | 压力和气流达到稳定条件 |

进入 `STABLE` 需要：

- 最近1秒样本已经完整；
- 平均压力大于0.30 kPa；
- 平均流量大于1.0 L/min；
- 压力变异系数不超过1.5%；
- 流量变异系数不超过2.0%；
- 上述条件连续保持约0.8秒。

稳定后，如果压力变异系数超过2.5%或流量变异系数超过3.0%，并持续约0.3秒，状态会退出 `STABLE`。

### 4.6 P/Q

`P/Q` 表示压力与流量之比：

`P/Q = 压力(kPa) ÷ 流量(L/min)`

它可用于比较气路、乐器或簧片系统的等效气动阻力。数值越大，表示单位流量所需压力越高。

最近1秒平均流量不超过1.0 L/min 时，P/Q 显示 `---`，避免接近零流量时比值失真。

### 4.7 Power

`Power` 为气动功率估算：

`Power(W) = 压力(kPa) × 流量(L/min) ÷ 60`

该数值表示当前压力和流量共同对应的气动功率，不等同于乐器声功率或声学效率。

## 5. 第二页：气压曲线

第二页显示最近10秒的气压变化。

| 参数 | 含义 |
|---|---|
| 页面顶部数值 | 当前滤波气压，单位 kPa |
| 曲线 | 最近10秒气压历史，右端为当前时刻 |
| `AVG` | 最近10秒窗口内的平均气压 |
| `MIN` | 最近10秒窗口内的最低气压 |
| `MAX` | 最近10秒窗口内的最高气压 |
| `-10 s / -5 s / 0 s` | 曲线时间位置 |

曲线以20 Hz刷新，纵轴根据最近数据自动选择约2、4、6、8或10 kPa上限，使不同压力范围下的变化都易于观察。

超量程时曲线时间轴继续滚动，在10 kPa上限处显示红线提示；红线不代表实际测得的压力，恢复量程内后继续显示正常曲线。

## 6. 第三页：气流曲线

第三页显示最近10秒的气流变化。

| 参数 | 含义 |
|---|---|
| 页面顶部数值 | 当前滤波气流，单位 L/min |
| 曲线 | 最近10秒气流历史，右端为当前时刻 |
| `AVG` | 最近10秒窗口内的平均气流 |
| `MIN` | 最近10秒窗口内的最低气流 |
| `MAX` | 最近10秒窗口内的最高气流 |
| `-10 s / -5 s / 0 s` | 曲线时间位置 |

曲线以20 Hz刷新，纵轴根据最近数据自动选择约10、20、30、40或50 L/min上限。

超量程时曲线时间轴继续滚动，在50 L/min上限处显示红线提示；红线不代表实际测得的流量，恢复量程内后继续显示正常曲线。

## 7. 第四页：统计

统计页分为压力列和流量列。压力单位为 kPa，流量单位为 L/min。

### 7.1 统计行

| 参数 | 时间范围 | 含义 |
|---|---|---|
| `AVG` | 最近1秒 | 平均值 |
| `MIN` | 当前测量会话 | 会话中的最低值 |
| `MAX` | 当前测量会话 | 会话中的最高值 |
| `P-P` | 最近1秒 | 最大值减最小值 |
| `Σ` | 最近1秒 | 标准差 |
| `CV` | 最近1秒 | 变异系数，`Σ ÷ |平均值| × 100%` |

CV 是不受量纲影响的相对稳定性指标。CV 越小，表示相对于平均值的波动越小。

压力 CV 仅在最近1秒数据完整且平均压力达到 `0.30 kPa` 后显示；流量 CV 仅在最近1秒数据完整且平均流量达到 `1.00 L/min` 后显示。低于相应阈值时显示 `---`。这是因为接近零压力或小流量时，微小的零点噪声会被 CV 公式中的近零平均值放大，此时 CV 没有有效的统计意义。

### 7.2 Stable P、Stable Q 和 P/Q

当设备进入 `STABLE` 时保存一组稳定测量结果：

- `Stable P`：进入稳定状态时最近1秒的平均压力；
- `Stable Q`：进入稳定状态时最近1秒的平均流量；
- `P/Q`：对应稳定压力与稳定流量之比。

设备尚未取得稳定结果时显示 `---`。

### 7.3 Volume

`Volume` 是当前测量会话内的累计气量，单位为 L：

`累计气量 = 流量随时间积分`

累计使用响应更快的流量数据和梯形积分，并自动补入会话确认前最多约0.2秒的有效气流，以减少气流快速变化时的遗漏。只有流量大于0.5 L/min时才进入累计，避免零点噪声长期累加。

如果会话期间压力或流量曾超量程，`Volume` 数值将显示为红色并带有 `!`。这表示超量程期间的气量无法准确累计，当前结果不完整，不应作为完整累计气量使用。

### 7.4 Duration

`Duration` 为当前或最近一次测量会话持续时间，格式为：

`小时:分钟:秒`

### 7.5 测量会话的自动开始与结束

测量会话自动开始条件：

- 压力大于0.20 kPa，或流量大于0.5 L/min；
- 条件持续约0.1秒。

测量会话自动结束条件：

- 压力低于0.20 kPa，并且流量低于0.5 L/min；
- 条件持续约2秒。

### 7.6 清除统计数据

在 `STATISTICS` 页面快速双击，屏幕会显示：

- `Yes`：清除会话数据和已保存的稳定结果；
- `No`：保留数据并关闭提示框。

## 8. 第五页：蓝牙

蓝牙页用于查看连接状态并控制实时数据发送。

### 8.1 STATUS

| 状态 | 含义 |
|---|---|
| `STARTING` | 蓝牙正在启动 |
| `ADVERTISING` | 正在广播，等待客户端连接 |
| `CONNECTED` | 已连接蓝牙客户端 |
| `UNAVAILABLE` | 蓝牙初始化失败或不可用 |

### 8.2 DEVICE

显示设备蓝牙名称，格式类似：

`AeroMeter-AM1-12AB34`

末尾6位来自 ESP32-S3 的硬件标识，用于区分多台 AeroMeter。

### 8.3 STREAM

控制实时数据通知：

- 开启：向已连接客户端发送实时测量数据；
- 关闭：保持蓝牙连接，但暂停实时数据通知。

固件默认开启 STREAM。

### 8.4 RATE

选择实时数据发送频率：

- `5 Hz`：较低数据量；
- `10 Hz`：中等数据量；
- `20 Hz`：默认设置，更高时间分辨率。

蓝牙数据包括滤波后的压力和流量、最近1秒的平均值、标准差、峰峰值、稳定状态及会话状态。客户端需要支持当前 AeroMeter BLE 协议。

## 9. 第六页：设备信息

`DEVICE INFORMATION` 用于查询设备身份和软件版本：

| 字段 | 含义 |
|---|---|
| SN | 出厂序列号，用于售后和校准记录查询；未登记时为 `UNREGISTERED` |
| HW | 硬件修订号；未登记时为 `UNSET` |
| UID | 芯片唯一标识，用于与出厂记录核对 |
| FW | 当前固件版本 |
| BUILD | 当前固件构建编号 |
| CAL | 默认显示 `FACTORY (SENSORS)`，表示两个传感器分别经过各自厂家出厂校准；录入后续校准报告后显示报告日期。不是整机校准证明；`RECORD ERROR` 表示记录读取异常。CAL 只显示校准来源/报告状态，不显示本次开机的气压偏移；气流没有开机补偿值 |
| SLOT | 当前固件存储槽及升级布局状态 |

需要登记或升级设备时，按工具提示在本页保持不移动长按约2秒，允许接下来的两分钟内开始写入。普通查看信息不需要长按。升级过程中显示 `FIRMWARE UPDATE`，测量暂停，请勿拔线或断电。升级完成并重新启动，通过连接检查、确认可能出现的气流提醒后再进行测量。

配套 PC 程序可通过 USB 数据线或蓝牙连接。`Auto` 同时寻找 USB 与蓝牙候选设备，列表优先排列 USB；已记住上次成功连接的设备时先尝试直连，失败自动重试一次，再回退到扫描到的符合条件的设备。连接方式更改后点击 `Refresh`。旧固件可能只支持蓝牙。使用升级工具前先断开 PC 测量程序和手机应用。

## 10. 数据处理说明

### 10.1 采样频率

- 传感器采样：100 Hz；
- 主界面刷新：10 Hz；
- 曲线刷新：20 Hz；
- 曲线历史长度：10秒。

### 10.2 滤波

压力和流量的显示与统计使用两级滤波：

1. 三点中值滤波，用于抑制单个异常尖峰；
2. 指数移动平均滤波，系数为0.10，用于平滑显示和统计数据。

累计气量使用同样的异常尖峰抑制，但采用响应更快的平滑参数，以减少快速变化气流带来的积分误差。滤波会降低噪声，但也会引入少量响应延迟。

### 10.3 超量程处理

- 气压达到10 kPa上限时显示红色 `OVER`；
- 气流达到50 L/min上限时显示红色 `OVER`；
- 负气压、负气流按零显示，不据此显示 `OVER`；这不表示设备可测量负压或反向流量；
- 超量程通道的无效读数不加入滤波和统计，另一个正常通道仍继续更新。曲线时间轴继续滚动，以顶部红线表示超量程；红线只是提示，不计入统计或累计气量。传感器读取失败时显示曲线缺口，不画超量程红线。如果当时正在测量会话中，累计气量会以红色 `!` 标记为不完整；
- 回到有效量程后自动恢复白色数字和正常数据处理。

超量程表示当前数值已超出保证范围，不应将超量程期间的换算数字作为有效测量结果。

最近10秒没有有效样本时，曲线页的 AVG/MIN/MAX 显示 `---`，而不是零。

## 11. 推荐测量方法

1. 确认设备内置的约10 cm直管、接口和气路完好且没有堵塞，无需另外加装直管；
2. 确认传感器和气路干燥、无异物；
3. 在无压力、无流量条件下开机；
4. 等待启动检查完成；如有气流提醒，检查环境后单击继续；如出现传感器警告，应排除连接问题并重启，不要在跳过警告的维护状态下测量；
5. 将被测乐器、嘴件或气路按正常方向连接；
6. 缓慢增加气压和气流，避免突然超过量程；
7. 观察第一页的实时值和稳定状态；
8. 需要动态分析时查看第二、三页曲线；
9. 稳定后在第四页读取 Stable P、Stable Q 和 P/Q；
10. 如需重新测量，在统计页双击并选择 `Yes` 清除旧结果。

## 12. 使用注意事项

- 本设备采用单向流量传感器；气流方向错误时可能始终显示零；
- 不要直接让唾液、水滴、油雾或粉尘进入流量传感器；
- 建议增加可更换的干燥过滤或防唾液结构；
- 不要依靠嘴直接猛烈吹气测试满量程，直接呼气很容易超过50 L/min；
- 超量程 `OVER` 是保护性提示，不代表传感器损坏；
- 开机气压归零期间须无外加压力、不要吹气；
- 进、出风口同时密封可能因温度、手部挤压或软管变形产生压力变化；
- 压力显示两位小数不代表准确到0.01 kPa，10 kPa、±0.25%FS传感器的理论误差约为±0.025 kPa。

### 12.1 呼气、潮湿与污染

测量气体应清洁、干燥且无冷凝水。人的呼气温暖、潮湿，还可能携带唾液；即使短时间吹气，也不能保证不会凝结。不要将嘴直接贴到设备接口。使用独立嘴件、软管和适合流量的防唾液/集水结构；应按使用场景评估过滤和干燥措施，不要把普通滤棉当作除湿器。颗粒过滤器不能去除水蒸气，集水器也不能保证去除全部湿气。

过滤器、软管和集水结构会增加阻力、改变响应，可能影响乐器实际工作状态。保持每次测试气路配置一致，检查是否潮湿、堵塞或漏气；不要用细小过滤器限制出口后猛烈吹气。不同用户应使用独立或按供应方方法清洁的外部嘴件，不共用接触口腔的部件。

若发现水滴、冷凝、异常持续偏移或响应变化，立即停止供气并断电。不要继续吹气“吹干”，不要用压缩空气、高温、酒精或溶剂冲洗内部传感器；联系供应方处理。设备没有在本文承诺防水等级或可水洗能力。外壳清洁前断电，仅擦拭外部，不让液体进入接口或 USB。

### 12.2 气路、环境与供电

按设备标注的进/出气方向连接，避免折弯、堵塞、松脱和同时封闭两端；检查连接牢固后缓慢增加气流。`OVER` 不是泄压功能，也不能保证超压不会损坏设备，应立即降低输入。不要接入未经限压的压缩气源。

避免直射阳光、高温、剧烈温差、结露、振动及风扇直吹。在测量地点放置至环境稳定再启动。本文未给出经过整机验证的温湿度范围；需要在特殊环境工作时先向供应方确认。长期漂移、摔落、液体侵入或气路改动后，应检查/校准，不要仅靠开机归零掩盖问题。

使用匹配设备额定要求的供电和完好的 USB 数据线。插拔外部传感器前应断电，不将带电插入后出现的数字当作有效测量。固件更新期间禁止断电、拔线或关闭工具；正常测量程序与烧录/升级工具不要同时占用 USB。存放前断电，保持气路干燥、接口清洁，避免异物进入。

## 13. Windows 桌面程序 1.2.1

### 13.1 安装与连接

下载官方发布的 Windows x64 ZIP，核对同一发布包的 SHA256SUMS.txt，完整解压后运行 `AeroMeter.exe`。不要只复制 EXE；同目录依赖文件不可删除。当前程序没有数字签名，系统可能提示未知发布者；校验和及一次杀毒扫描不等同于数字签名，也不能保证所有电脑都不误报。不要因此关闭系统安全保护，来源/校验异常时联系供应方。

先确认设备正常启动、没有红色传感器警告。USB 连接使用数据线（仅充电线不能通信）；蓝牙连接需要电脑有正常启用的 BLE 适配器。选择 `Auto`、`USB` 或 `BLE`，点击 `Refresh` 后选择设备并 `Connect`；已保存设备会尝试自动直连。不要让手机或其他软件同时连接同一设备。点击 `Disconnect` 主动断开，正常关闭程序也会释放连接。

### 13.2 页面与操作

- `LIVE VIEW`：实时气压/气流、最近10秒曲线、AVG/MIN/MAX、Σ、P-P、状态、P/Q 和 Power；单位与设备一致。
- `STATISTICS`：近期 AVG/P-P/Σ/CV、会话 MIN/MAX、稳定测量值、累计气量与时长。小压力/小流量的 CV 显示 `---`，不是故障。
- `RESET STATISTICS`：显示二次确认后清除电脑端统计，不清除设备端统计，不更改校准或固件。
- 当前 PC 界面不提供 BLE STREAM/LIVE RATE 设置，不含 CSV 导出功能，也不是固件烧录/序列号管理工具。

### 13.3 与设备读数的关系和限制

实时及1秒统计由设备通过 Protocol 1 发送，压力和流量按两位小数传输。电脑端10秒历史、会话极值和累计气量来自收到的数据，不保证与设备每一刻完全相同；无线刷新率、传输延迟、丢包及连接开始时间都会影响结果。

设备累计气量使用100 Hz采样链路的较快流量数据；PC 根据收到的5/10/20 Hz实时流量及电脑计时进行积分。快速变化气流时差异可能增加，不能以传感器 ±1.5% 作为 PC 累计气量的保证误差。超量程或明显通信中断后的累计结果应视为不完整；不得把红色 `!` 结果作为完整气量。

**重要限制：Protocol 1 没有传感器缺失/气压归零未完成的有效性标志。PC 可能仍显示零或之前的读数，不能凭电脑出现数字判断传感器正常。必须先检查设备启动和红色提示；发生传感器错误、拔插或异常读数时停止测试，排除问题后重新启动设备并开始新测量。**

## 14. 第三方开发接口

公开的 Protocol 1 可供自编软件、数据分析和教学接入，USB 与 BLE 使用相同的测量数据布局。公开范围是设备识别、实时/统计数据读取以及数据流控制，不包括固件升级、校准、签名、生产或序列号写入。不要猜测未公开命令。

| 项目 | 说明 |
|---|---|
| BLE 服务 | `8d530001-6c90-4a36-9c5f-5a07d0a11000` |
| BLE 特征 | UUID首段 8d530002：设备信息 Read；8d530003：实时 Notify；8d530004：统计 Notify；8d530005：数据流控制 Write；后缀均与服务相同 |
| 实时包 | 14字节，小端；版本/类型、序列号、启动毫秒、压力、流量、状态及标志 |
| 统计包 | 20字节，小端；1秒压力与流量的均值、Σ、P-P |
| 数值换算 | 压力 kPa、气流 L/min；整数除以100；该编码步距不代表准确度 |
| 超量程标志 | 0x02 压力、0x04 气流；0x01 表示会话进行中，不表示传感器健康 |
| USB | 候选 VID/PID 303A/1001；115200，DTR/RTS 关闭；`@AM1 ` 前缀 JSON 行，LF 结束；必须用 info 确认产品 |
| USB 公开请求 | info、stream、ping；建议每1.5秒 ping 保持连接 |
| 发送频率 | USB实时20 Hz；BLE实时5/10/20 Hz；统计1 Hz，与100 Hz内部采样不同 |

完整字段偏移、UUID、命令、示例、错误处理及兼容性规则见 [中文接入指南](https://github.com/andyxuhang/AeroMeter-Desktop/blob/main/protocol/AEROMETER_PROTOCOL_1.md)及[英文接入指南](https://github.com/andyxuhang/AeroMeter-Desktop/blob/main/protocol/AEROMETER_PROTOCOL_1_EN.md)；发布 ZIP 中也附有指南。参考源码位于公开仓库 `protocol/shared_protocol/python/galeon_protocol`，许可见仓库 LICENSE 和第三方声明。

开发时必须校验包长度、版本和类型，按标志处理 OVER，处理计数回绕、丢包、重连与无数据超时。负数/非有限数可能编码为零，零值不能证明真实无流量；不可从此接口推断传感器健康。第三方程序自行累计气量时应记录缺失区间并标记结果不完整，不把缺包补为有效零流量。二次开发不应改变或绕过设备安全/维护权限。

## 15. 故障处理与交付检查

| 现象 | 建议 |
|---|---|
| SENSOR WARNING / 页面红字 | 停止测量，断电检查连接、供电和气路，再启动；长按跳过仅供维护 |
| PRESSURE ZERO FAILED | 解除压力并与大气相通后重新启动；重复失败联系供应方 |
| POSSIBLE AIRFLOW | 检查环境/残余气流；仅提示，可单击继续，但不说明传感器已校准 |
| 静止有少量流量或慢漂移 | 气流不做开机归零；检查湿气、风、漏气及环境，勿据此认定精度提高或设备损坏 |
| OVER / 红线 | 降低压力/流量；该时段不是有效测量；重置后重新测试累计气量 |
| USB 无设备 | 检查数据线、USB端口、系统设备识别；关闭其他占用软件，Refresh 后重试 |
| BLE 找不到/连不上 | 启用蓝牙，关闭手机等连接，靠近设备，查看第5页广播状态后 Refresh；切换到 USB 排查 |
| PC 有数字但设备报错 | 不能继续测量；参阅13.3，排除故障并重启 |

交付前供应方应登记 SN/HW/固件及桌面版本，确认启动、无气流基线、已知压力/流量点、超量程、USB、BLE 和恢复行为，并提供实际校准/检验记录。用户首次使用先完成上述正常启动及连接检查。有故障请提供 SN、FW、BUILD、桌面版本、提示照片和复现步骤，避免自行拆开传感器。
